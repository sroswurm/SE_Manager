# SE Manager

Enterprise software prototype for managing the business operations of a structural engineering practice.

## Overview

SE Manager is a dashboard ecosystem designed to streamline the non-technical side of running a structural engineering firm. It brings project administration, financial tracking, and client management into a single platform — replacing the patchwork of spreadsheets, shared drives, and disconnected tools that most small-to-mid-size practices rely on.

## Core Modules

### Project Intake & Folder Creation
- Standardized new-project onboarding workflow
- Automated folder structure generation for consistent document organization
- Project metadata capture (client, scope, deadlines, assigned engineers)

### Document Management
- Centralized storage and retrieval of project documents
- Version tracking for plans, calculations, and reports
- Integration with the project folder structure

### Quotes & Proposals
- Proposal generation and tracking
- Fee estimation tools
- Pipeline visibility from initial inquiry through signed contract

### Invoicing & Profitability
- Invoice creation and status tracking
- Project-level profitability analysis
- Revenue dashboards and financial reporting

## Goals

- Reduce administrative overhead so engineers can focus on engineering
- Provide firm leadership with real-time visibility into workload, pipeline, and finances
- Establish repeatable processes that scale as the practice grows
- Serve as a working prototype to validate workflows before committing to a full build

## Status

Early-stage prototype. Architecture and technology decisions are in progress.
